# To-Do List Web App

## Project Description
This project is a simple To-Do List Web Application developed using HTML, CSS, and Vanilla JavaScript.

It allows users to add tasks, mark tasks as completed, and delete tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
- VS Code

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Instant updates without page refresh

## Project Structure
- index.html
- style.css
- script.js

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Start adding your tasks!

## Outcome
Learned DOM manipulation, event handling, and dynamic UI updates using JavaScript.
